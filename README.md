## Usage (`shopper-ingest`)

Console script defined in `pyproject.toml` as
`shopper-ingest = "shopper_composite.cli:main"`. Defaults match the radish
layout; cron can call the bare form with no arguments.

```bash
# cron / default form: every option falls back to its default
uv run shopper-ingest

# every option spelled out
uv run shopper-ingest \
  --download-path /home/lcalleja/stats.csv \
  --secrets /home/lcalleja/shopper_composite/secrets.yaml \
  --table shopper_log \
  --start 2023-02-03

# help text generated by argparse
uv run shopper-ingest --help

# local development on the laptop (note: wget to check-in-desk only resolves on radish)
uv run shopper-ingest \
  --download-path /tmp/stats.csv \
  --secrets /Users/casita/code/shopper_composite/secrets/secrets.yaml \
  --table shopper_log

# equivalent without the console script
uv run python -m shopper_composite.cli --table shopper_log
```

CLI options:

| Flag | Default | Purpose |
| --- | --- | --- |
| `--download-path` | `/home/lcalleja/stats.csv` | where wget writes the plum CSV |
| `--secrets` | `/home/lcalleja/shopper_composite/secrets.yaml` | YAML with host/user/password/database/port |
| `--table` | `shopper_log` | destination table |
| `--start` | `2023-02-03` | start date used only when the table is empty |

## Module synopses (`src/shopper_composite/`)

### `__init__.py`
Package marker. Defines a placeholder `main()` that prints a greeting; the
ingest console script points at `cli.main()` instead.

### `cli.py`
Entry point and orchestrator for the daily ingest. Parses CLI args via
`build_parser()`, configures logging from `logging_reference.LOGGING`, opens
one DB connection, and runs fetch -> transform -> append (upsert) inside it.
Returns process exit code 0 on success.

Defaults (overridable by flags): `--download-path`, `--secrets`, `--table`,
`--start`.

Control flow (`main()`):
```
main()
├── args = build_parser().parse_args()
├── logging.config.dictConfig(LOGGING)
├── creds = db_connector.get_config(args.secrets)
└── with db_connector.connect(creds) as conn
    ├── latest = db_connector.latest_date(conn, args.table)
    ├── start = latest or args.start
    ├── fetch.download2(args.download_path, start.isoformat())
    ├── rows = transform.transform_rows(args.download_path, after=latest)
    └── if rows: db_connector.append(conn, args.table, rows)  # else rows_written = 0
```

### `db_connector.py`
All MySQL access. Queries the latest date in the table and later upserts rows
(after transform.py).
Functions:
  - `get_config(yaml_file: str)` loads `host`, `user`, `password`, `database`, `port` from a YAML secrets file into a dict.
  - `connect(creds_dict: dict|None = None)` is a context manager yielding a `mysql.connector` connection (falls back to `get_config("/home/lcalleja/shopper_composite/secrets.yaml")`) and closes it on exit.
  - `latest_date(conn, table: str)` returns `MAX(date)` or `None`.
  - `append(conn, table: str, rows: list[tuple])` runs `executemany` INSERT ... ON DUPLICATE KEY UPDATE, commits, and returns `len(rows)`; rolls back and re-raises on error.

### `fetch.py`
Downloads the check-in report from plum.
Functions:
  - `download2(dest: Path, start_dt: str, timeout: int = 60)` runs `wget -O <dest> check-in-desk:8888/stats?format=csv&start=<start_dt>` via `subprocess.run(check=True)`; a non-zero exit raises `CalledProcessError` after logging. Hardcoded: the `check-in-desk:8888` host and `format=csv`.

### `transform.py`
Converts the downloaded CSV into insert-ready tuples.
Functions:
  - `transform_rows(csv_path: str | Path, after: date | None = None)` reads the file with `csv.DictReader`, parses `date` as ISO, skips rows where `date < after` (keeps `after` so `append` can upsert the latest day), and coerces the count columns through `_to_smallint` (blank -> `None`). Returns `[(date, ghfc, trial, psfc, cbfc, visitor), ...]`. Hardcoded: `INT_COLS = ("ghfc", "trial", "psfc", "cbfc", "visitor")`.

### `logging_reference.py`
`LOGGING` dict for `logging.config.dictConfig`. File handler writes ERROR+ to
`log_testing.log` (relative to the process cwd).
